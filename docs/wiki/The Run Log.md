# The Run Log

What each run did, line by line. Open it with **Run log** on the canvas.

Each run shows when it ran, how it started, and its counts: sources checked, items found, added,
held back and failed. Expand a run to read its lines — which sources were checked, which were skipped
and why, what was filed where, and what went wrong.

## Filters

- **Everything**
- **Started by me** — Run now, Backfill and the command line.
- **On a schedule** — runs the clock started.
- **Went wrong** — finished runs that failed.

## Retention

The last 40 runs keep their full lines; older runs keep only their counts. A run writes at most 600
lines.

## While a run is going

The canvas lights the boxes and wires it is working through, and a run still in progress can be read.
