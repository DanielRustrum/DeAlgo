Plugins

{{ plugins | length }}

A plugin is one .lua file. It says what a reference like r/python or @handle is and where that source's feed lives; De-Algo does the fetching, so a plugin never touches the network, your credentials, or anyone else's data.

Switching one off leaves the file where it is and stops it being asked anything. Sources already being watched keep their own feed address and carry on — what stops is recognising new ones. It is the only way to turn off a plugin that ships with De-Algo.

Add one

It lands in {{ folder }} and is read straight away. A file named after one that ships with De-Algo replaces it, which is how you change a shipped plugin without editing the image.

A plugin is code, and it runs here. It is walled off — no files, no network, no credentials, and it is stopped if it loops or eats memory — but it still reads every reference you add. Add ones you would be willing to read.

Writing one

{{ example }}

What you return is configuration. It says what the plugin is and what it offers, and nothing in it acts by itself. Anything it does to the site goes through dealgo, which it is handed rather than importing.

recognise is the whole of a source: given what somebody typed, answer with the key to file it under and the address of its feed, or nothing at all if it is not yours. Return guess = true when you are offering rather than asserting — a certain answer from another plugin then wins, which is what stops a Bluesky handle from swallowing every domain name.

dealgo is always there, and answers nothing it was not granted: dealgo.version and dealgo.permissions() always; dealgo.sources() and dealgo.feeds() with see what you are watching; dealgo.watch(), dealgo.tag() and dealgo.pause() with change what you are watching. All of it is about the one account whose work is in hand — never another's, and nothing at all outside a run.

dealgo.permissions() is a plugin's own manifest read back: each thing it asked for, the reason it gave, and whether it was granted. A plugin that asked for the network and did not get it can say so, or quietly do the lesser thing, rather than failing at the moment it reaches for something that is not there.
