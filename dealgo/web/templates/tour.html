{% if current.key == 'welcome' %}

De-Algo watches the sources you choose and puts whatever they publish into a feed, oldest first. Nothing else gets in: no recommendations, no autoplay trail, no “you might also like”.

Four things make it work — a feed to collect things, a source to fill it, a link between them, and a sync to do the work. The rest of this tour sets those up in order.

Already have some of it? The ticks on the left show what is done.

{% elif current.key == 'feed' %}

A feed is the list De-Algo keeps filled. It can be a real YouTube playlist, or a generic feed that lives only here — which needs no Google account and spends no API quota.

On Configuration, press New feed and pick one of the three routes.

Start generic if you just want to try it: nothing leaves this machine.

{% elif current.key == 'channel' %}

Press Track content on Configuration and paste wherever you want to follow: a YouTube channel URL, an @handle or a bare UC… id; an r/ community; a Bluesky handle; a Substack; or the address of any RSS or Atom feed.

The same box asks how far back to reach on the first check. Only a YouTube handle needs credentials — a UC… id and everything else need none at all.

Only YouTube videos can go into a real YouTube playlist. Everything else fills a feed that lives here, and is read here.

{% elif current.key == 'link' %}

A source with no feed stays paused — polling it would only queue things with nowhere to go.

Link them from either side: a feed's page lists the channels that fill it, and a channel's page lists the feeds it fills. Linking the first one starts the channel watching.

{% elif current.key == 'connect' %}

Only needed for feeds backed by a real YouTube playlist, and only to write to it. Without an account De-Algo still polls channels, filters them and fills every feed for watching here — it simply leaves YouTube alone until you connect, then catches the playlists up.

In Settings, add a Google OAuth client, then press Connect YouTube account. The page shows the exact redirect URI to register.

{% if not progress.has_youtube_feed %}

None of your feeds needs this yet — they are all generic.

{% endif %} {% elif current.key == 'sync' %}

On Configuration, open a trigger box and press Run now. De-Algo reads the public feed of everything that trigger is wired to — which costs no API quota — filters what is new, and puts what survives into your feeds, oldest first.

Backfill beside it takes everything those feeds still list rather than only what is new, which is how you catch up on a source you have just added.

After that it runs on its own, every {{ settings.poll_interval_minutes if settings else 30 }} minutes by default.

{% elif current.key == 'watch' %}

Feed is where you watch. Each feed is a collapsed section; open one and click a thumbnail to play it in place.

Focus ▶ plays the unwatched queue straight through, marking each one watched as it ends.

{% else %}

Day to day there is not much to do:

  • Mark things watched as you go, then Remove watched to clear them out of the playlists.
  • Use Raw to see every video De-Algo has seen and why it was skipped.
  • Watch the quota in Settings. Polling is free; only playlist writes cost anything, and De-Algo stops before YouTube refuses it.
  • If quota is tight, the fill order on Configuration decides who gets in first.

Done with this? You can hide the Tour button in Settings.
