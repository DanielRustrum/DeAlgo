Algorithms

{{ 'allowed' if algorithms_allowed else 'switched off' }}

Each account can have an algorithm of its own: it learns from how that account watches in Focus mode, and an Aggregation piece on the canvas uses it to filter, sort or expire. It learns and predicts here, on this machine's processor, on every run for every account using it — which on a small machine can be more than it should carry.

Switched off, Aggregation pieces do nothing and nothing is learned. What Focus mode remembers is kept, so switching back on picks up where it was.

Move this instance

Every account and every setup at once: who the accounts are, what each of them watches, and how each is configured. The file for standing Pamphlets up on another machine.

No secrets are in it — no passwords, no sign-ins, no plugin settings. A file like this gets copied between machines and left in a Downloads folder, so the accounts come across and their credentials do not: you set a new password for each on the Accounts page, and each signs in to its plugins again. It is still encrypted, because who your accounts are and what they watch is nobody else's business.

Load one

Adds to this instance rather than replacing it: accounts that are not here are created, and each account's feeds and channels are restored into its own space. Nothing already here is deleted. The admin account stays this machine's — it comes from the environment, not from a file. Restored accounts arrive without a password and cannot be signed in to until you set one on the Accounts page; Pamphlets says which ones when it is done.
