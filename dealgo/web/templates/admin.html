Move this instance

Every account and every setup at once: who the accounts are, what each of them watches, and how each is configured. The file for standing De-Algo up on another machine.

No secrets are in it — no passwords, no sign-ins, no plugin settings. A file like this gets copied between machines and left in a Downloads folder, so the accounts come across and their credentials do not: you set a new password for each on the Accounts page, and each signs in to its plugins again. It is still encrypted, because who your accounts are and what they watch is nobody else's business.

Load one

Adds to this instance rather than replacing it: accounts that are not here are created, and each account's feeds and channels are restored into its own space. Nothing already here is deleted. The admin account stays this machine's — it comes from the environment, not from a file. Restored accounts arrive without a password and cannot be signed in to until you set one on the Accounts page; De-Algo says which ones when it is done.
