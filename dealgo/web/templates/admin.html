Move this instance

Every account and every setup at once: who the accounts are, what each of them watches, and how each is configured. The file for standing De-Algo up on another machine.

No secrets are in it — no passwords, no Google connections, no API keys. A file like this gets copied between machines and left in a Downloads folder, so the accounts come across and their credentials do not: you set a new password for each from this page, and each reconnects its own Google. It is still encrypted, because who your accounts are and what they watch is nobody else's business.

Load one

Adds to this instance rather than replacing it: accounts that are not here are created, and each account's feeds and channels are restored into its own space. Nothing already here is deleted. The admin account stays this machine's — it comes from the environment, not from a file. Restored accounts arrive without a password and cannot be signed in to until you set one above; De-Algo says which ones when it is done.

How accounts work here

The admin
{{ admin_user }}, set with DEALGO_ADMIN_USER and DEALGO_ADMIN_PASSWORD. De-Algo takes that password from the environment on every start, so changing the variable and restarting is the way back in if it is lost — and the reason it cannot be changed on this page.
Everyone else
Uses the feeds: the feed, Focus mode, channels and feeds. Settings, backups, the Google connection and this page are the admin's alone.
Sessions
A signed-in browser holds a random token for {{ session_days }} days. Only a hash of it is stored, so this database is not enough to sign in as anyone. Switching an account off, deleting it, or changing its password ends its sessions at once.
