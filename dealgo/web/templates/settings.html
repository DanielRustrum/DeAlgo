Restore

Loads a backup back in. Feeds and channels are matched by their YouTube ids, so anything the file names is created or brought up to date — nothing is deleted.

{# A file upload needs a real form post, not a boosted fetch. #}

No credentials are in the file — not the YouTube sign-in, not the Google client id and secret. A backup sits in a Downloads folder for years, and both are re-entered in a minute. On a new machine: restore the file, paste the client id and secret below, then press Connect YouTube account.

How De-Algo spends quota

Channel polling uses YouTube's public Atom feed and costs nothing, so a short interval is fine. Only playlist writes are expensive: each added video costs 50 of the default 10,000 daily units, which works out to about 200 videos a day.
