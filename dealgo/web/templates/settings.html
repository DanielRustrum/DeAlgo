Back up your setup

Your feeds and channels, as plain JSON, with no credentials in it. The admin can take an encrypted backup of the whole instance — every account — from the Admin page; this one is yours alone.

The whole setup as one JSON file: feeds, channels, filters, limits and fill order. Keep it somewhere safe, or carry it to another machine.

{# hx-boost must not touch this: a boosted request fetches the file as AJAX and swaps it into the page instead of saving it. #}

Restore

Loads a backup back in. Feeds and channels are matched by their ids, so anything the file names is created or brought up to date — nothing is deleted.

{# A file upload needs a real form post, not a boosted fetch. #}

No credentials are in the file — no sign-in to any plugin's service, and none of a plugin's settings. A backup sits in a Downloads folder for years, and a sign-in is redone in a minute. On a new machine: restore the file, then sign in again under Plugins above.
